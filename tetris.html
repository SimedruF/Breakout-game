🎮 TETRIS

The Classic Falling Blocks Puzzle Game

Controls

Move: ← → Arrows
Rotate CW: ↑ / X
Rotate CCW: Z
Soft Drop: ↓
Hard Drop: SPACE
Hold: C / Shift
Pause: P
Start: SPACE

Features

  • Classic Tetris gameplay with SRS rotation
  • Ghost piece shows landing position
  • Hold piece system
  • Next piece preview
  • Progressive difficulty (speed increases with level)
  • Score system with line clear bonuses
  • Smooth DAS/ARR controls
  • All 7 standard tetrominos (I, O, T, S, Z, J, L)
